# Tienda Don Pedro

Sistema de gestión de inventario, clientes y ventas de la Tienda Don Pedro.

## Productos principales
- Pan tajado
- Leche
- Arroz 1kg
- Huevos, Café y Panela

## Estructura del proyecto

| Archivo / Carpeta | Descripción |
| :--- | :--- |
| `datos/productos.txt` | Catálogo de productos y precios vigentes |
| `datos/clientes.txt` | Registro de clientes y direcciones |
| `datos/fiado.txt` | Control de cuentas fiadas |
| `datos/descuentos.txt` | Porcentajes de descuento para clientes frecuentes |
| `datos/domicilios.txt` | Tarifas de envío por barrio |

## Cambios realizados
- Actualización de catálogo y precios de productos.
- Creación de módulos de fiado, descuentos y domicilios mediante ramas en Git.
- Resolución de conflictos de precios en el catálogo.
